# Security and privacy

Please do not attach real resumes, contact details, private source documents,
or generated user PDFs to public issues or pull requests.

If you discover a privacy or security problem, report it privately through
GitHub's security advisory feature instead of opening a public issue.

Before publishing changes, inspect the staged file list and run:

```bash
scripts/privacy-scan --staged
```

The scanner is a release safeguard, not a substitute for human review.
